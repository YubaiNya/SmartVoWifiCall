NewVoWiFi is a separate Android IMS integration developed for this user's device.
It bundles the existing SoftVoWiFi 0.3.48 arm64 engine as a binary dependency.
The original engine's supplied notices are preserved in licenses/.
The dependency's complete engine source is not part of this project.
Neither the original SoftVoWiFi application nor its module is required at runtime.
NewVoWiFi reads current SIM credentials and publishes network observations itself.
The bundled derived engine changes 16 data bytes to isolate four state paths;
its protocol/authentication code remains identical to the preserved original.
It also bundles the official MetaCubeX/mihomo Android arm64 binary (GPL-3.0,
see licenses/MIHOMO-GPL-3.0.txt) solely to proxy Wi-Fi Calling traffic over an
isolated Linux TUN interface (wfctun0) without starting an Android VPN.
No SIM configuration, subscriber identifier, or runtime log is packaged here.
